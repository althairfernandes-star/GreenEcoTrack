# GreenEcoTrack

## Sobre o Projeto

O GreenEco Track é um projeto desenvolvido como Trabalho de Conclusão de Curso (TCC) do curso de Análise e Desenvolvimento de Sistemas da Universidade Wyden Unimetrocamp.

## Objetivo

Desenvolver uma plataforma tecnológica para monitoramento e gerenciamento de resíduos urbanos reutilizáveis, promovendo sustentabilidade ambiental e economia circular.

## Problema

O descarte irregular de resíduos causa impactos ambientais, sociais e econômicos. O projeto busca criar uma solução tecnológica para auxiliar no monitoramento e reaproveitamento desses materiais.

## Funcionalidades Planejadas

- Cadastro de usuários
- Consulta de ecopontos
- Registro de descarte de resíduos
- Monitoramento de indicadores ambientais
- Relatórios para cooperativas e órgãos públicos
