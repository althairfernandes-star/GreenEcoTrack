# Requisitos Funcionais

## RF01 - Cadastro de Usuários
O sistema deve permitir o cadastro de usuários.

## RF02 - Autenticação
O sistema deve permitir que os usuários realizem login.

## RF03 - Recuperação de Senha
O sistema deve permitir a recuperação de senha.

## RF04 - Consulta de Ecopontos
O sistema deve permitir a consulta dos ecopontos disponíveis.

## RF05 - Registro de Descarte
O sistema deve permitir o registro de descartes de resíduos.

## RF06 - Consulta de Histórico
O sistema deve permitir a consulta do histórico de descartes realizados.

## RF07 - Acompanhamento de Pontuação Sustentável
O sistema deve permitir que o usuário acompanhe sua pontuação sustentável.

## RF08 - Confirmação de Recebimento
O sistema deve permitir que as cooperativas confirmem o recebimento dos resíduos.

## RF09 - Gerenciamento de Coletas
O sistema deve permitir o gerenciamento de coletas pelas cooperativas.

## RF10 - Monitoramento de Indicadores
O sistema deve permitir o monitoramento de indicadores ambientais.

## RF11 - Gerenciamento de Ecopontos
O sistema deve permitir o cadastro e atualização de ecopontos.

## RF12 - Consulta de Relatórios
O sistema deve permitir a consulta de relatórios ambientais.

## RF13 - Gerenciamento de Usuários
O sistema deve permitir ao administrador gerenciar usuários do sistema.
