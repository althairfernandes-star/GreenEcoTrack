# Requisitos Não Funcionais

## RNF01 - Usabilidade
O sistema deve possuir interface intuitiva e de fácil utilização para todos os usuários.

## RNF02 - Desempenho
O sistema deve responder às solicitações dos usuários em tempo adequado.

## RNF03 - Segurança
O sistema deve exigir autenticação por login e senha para acesso às funcionalidades restritas.

## RNF04 - Disponibilidade
O sistema deve estar disponível para acesso pela internet sempre que possível.

## RNF05 - Compatibilidade
O sistema deve funcionar nos principais navegadores modernos.

## RNF06 - Escalabilidade
O sistema deve permitir futuras expansões sem necessidade de reconstrução completa.

## RNF07 - Manutenibilidade
O código e a documentação devem ser organizados para facilitar futuras manutenções.

## RNF08 - Confiabilidade
As informações cadastradas devem ser armazenadas de forma segura e consistente.

## RNF09 - Portabilidade
O sistema deve poder ser executado em diferentes ambientes e plataformas.

## RNF10 - Sustentabilidade da Informação
O sistema deve manter registros históricos das ocorrências e descartes para análise e geração de relatórios.
